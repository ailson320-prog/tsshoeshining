T&S Shoe Shining Website

A responsive business website developed for T&S Shoe Shining, designed to establish an online presence and provide customers with information about professional shoe-shining services.

Live Website

https://tsshoeshining.netlify.app/

Technologies Used

* HTML5 – Website structure and semantic markup
* CSS3 – Styling, layout, and responsive design
* JavaScript (ES6+) – Client-side functionality and interactivity

Project Overview

This project demonstrates front-end web development skills through the creation of a professional website for a shoe-shining business.

The goal is to provide visitors with a clean, accessible, and user-friendly experience across desktop and mobile devices.

Features

* Business-focused website design
* Mobile-friendly layouts
* Clear presentation of business information
* Organized page structure
* Styling using modern CSS techniques

Project Structure

The project uses HTML, CSS, and JavaScript files to separate page structure, visual styling, and interactive functionality.

Getting Started

1. Clone the repository:
    git clone https://github.com/ailson320-prog/tsshoeshining.git
2. Open the project folder.
3. Open index.html in your browser, or use the Live Server extension in Visual Studio Code.
